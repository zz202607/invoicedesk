# Ideas（搁置的想法）

> 不是承诺。每条写“收益 / 成本 / 风险”，每个里程碑评审一次；不打断当前模块。

| 想法 | 收益 | 成本 | 风险 |
|---|---|---|---|
| 从历史报销行学习“里程/餐费”模式，自动生成无票行 | 高 | 中 | 模式误判，需要确认 |
| 发票自动关联里程行（按日期/金额/公司） | 高 | 中 | 关联错误难发现 |
| 费用额度看板（餐饮 5‰、招待 5‰、福利 14%、广告 15%）（Phase 4） | 中 | 低 | 需要录入收入，增加步骤；汇总看板已能显示分类合计 |
| 扫描件 OCR（本地 Tesseract） | 中 | 高 | 中文票面准确率不稳 |
| OFD 支持 | 中 | 中 | 解析库选择与维护成本 |
| 自定义 Excel 模板映射 | 中 | 高 | 模板样式差异导致格式错 |
| 发票归档库（复制入库、源文件可移动） | 中 | 低 | 磁盘占用、重复存储 |
| 多页 PDF 快速拆条预览 | 中 | 低 | 拆错影响导出 |
| 重复票审查视图（跨批次） | 高 | 低 | 误报需要人工判断 |
| 发票真伪核验（手动跳转税局） | 低 | 低 | 无法自动、只提供链接 |
| 报销单行内“附件缩略图” | 中 | 低 | 表格性能 |
| 一键生成“报账包”ZIP（Excel+PDF+说明） | 高 | 低 | 无 |
| “本月报账”向导（导入→OCR→分类→生成行→导出，一步一屏） | 高 | 中 | 向导步骤过多反而拖慢；需保留高级入口 |
| 待确认审阅队列（只列待人工的票，↑/↓ + 批量确认 + 撤销） | 高 | 低 | 确认后撤销需与审计留痕一致 |
| 分类建议（历史修正相似度/销售方近邻，给出 2–3 个候选） | 高 | 中 | 建议错误会诱导误分类，必须可忽略 |
| 重复票/冲突审查视图（同票号聚合、双栏对比、保留一张） | 高 | 中 | 删除入口需谨慎，建议先归档不物理删除 |
| 导入预检与可取消进度（先报张数/重复/预计 OCR 时间） | 中 | 中 | OCR 中止后需保证事务与临时文件清理 |
| 发票缩略图网格与多选批量改分类 | 中 | 中 | 781 行渲染与内存占用 |
| 每字段可解释（置信度 + OCR 原文 + 命中的分类规则） | 中 | 中 | 需额外存储 OCR 文本，库体增大 |
| 去掉 Vue `unsafe-eval`：runtime-only + 预编译模板，UI 改由本地 HTTP 源加载 | 中 | 中 | 资源路径与 CSP 需重测；打包方式变化 |
| 规则删除后标记或清理孤儿 `learned.seller` 来源 | 中 | 低 | 规则已删但来源标记仍在，界面“规则分类”会误导；改动历史来源需审计 |
| 回溯批次撤销（按 edited_at 回滚一批分类） | 中 | 中 | 与人工修正交织时难判定回滚边界 |
| 发票票型可人工修正（当前只读） | 低 | 低 | 票型影响导出标签，需同步校验 |
